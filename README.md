# Proyecto de ejemplo

Materia: Seminario de Motores de Videojuegos I

## Uso

1. Clonar el repositorio
2. Abrir el proyecto en Unity
3. Descargar los assets gratuitos para terrenos: https://assetstore.unity.com/packages/3d/environments/unity-terrain-urp-demo-scene-213197
4. Ejecutar la escena en la carpeta `Clase`
